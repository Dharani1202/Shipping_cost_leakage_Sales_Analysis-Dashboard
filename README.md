# Shipping Cost Leakage Analysis
Analyzed shipping cost data using Power BI to identify cost leakages. Cleaned dataset in Power Query, applied DAX formulas, and visualized insights through column, bar, donut, funnel, tree map, and cluster charts. Dashboard highlights shipping cost by order priority, ship mode, product category, and container.
## Overview

This Power BI project analyzes shipping cost data to identify potential leakages. The dataset was sourced from Google, cleaned using Power Query Editor, and enhanced with DAX formulas to generate actionable insights.

## Data Cleaning

- Removed unnecessary columns and handled missing values.
- Standardized data formats for consistent analysis.
- Prepared dataset for visualizations and calculations.

## Visualizations

- Order Priority: Column chart showing shipping cost distribution.
- Ship Mode: Funnel chart displaying shipping cost by shipping mode.
- Product Category: Donut chart highlighting shipping cost per category.
- Product Container: Tree map visualizing shipping cost by container type.
- Customer Analysis: Cluster visualization for shipping cost and count of Row IDs by customer.
- Summary Table: Table for customer name, shipment mode, sum of sales, sum of shipping cost, and sum of profit.

## Key Insights

- Identified high shipping cost areas by order priority and ship mode.
- Analyzed shipping cost trends across product categories and containers.
- Observed customer-wise shipping cost patterns to uncover inefficiencies.
